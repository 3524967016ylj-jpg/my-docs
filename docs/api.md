# API 参考

本页面介绍文档网站示例中的 API 接口定义，包括请求方法、请求路径、功能说明和返回数据格式。

**注意：本页面中的 API 仅用于技术文档展示，不提供真实的后端服务。**

## 1. API 概述

API（Application Programming Interface，应用程序编程接口）用于定义不同软件组件之间的交互方式。

在 Web 开发中，前端应用通常通过 HTTP 请求访问后端接口，后端处理请求后返回相应的数据。

本项目使用一个简单的文档列表查询接口作为示例。

## 2. 查询文档列表

### 接口基本信息

| 项目     | 内容                     |
| -------- | ------------------------ |
| 接口名称 | 查询文档列表             |
| 请求方法 | GET                      |
| 请求路径 | /api/docs                |
| 返回格式 | JSON                     |
| 接口功能 | 获取网站中的文档条目列表 |

### 请求说明

- 请求方法：GET
- 请求路径：`/api/docs`
- 请求参数：本示例不需要额外参数。
- 功能说明：请求文档列表，返回文档的编号和标题。

### 返回示例

```json
{
  "items": [
    {
      "id": 1,
      "title": "使用指南"
    }
  ]
}
```

### 返回字段说明

| 字段  | 类型    | 说明         |
| ----- | ------- | ------------ |
| items | Array   | 文档条目列表 |
| id    | Integer | 文档唯一编号 |
| title | String  | 文档标题     |

## 3. 请求示例

在实际 Web 开发中，可以使用 HTTP GET 请求访问接口。

例如：

```bash
curl -X GET https://example.com/api/docs
```

上述地址仅为演示示例，并不代表本项目已经部署了对应的后端接口。

## 4. HTTP 请求方法简介

常见的 HTTP 请求方法包括：

| 请求方法 | 主要用途           |
| -------- | ------------------ |
| GET      | 获取资源           |
| POST     | 创建资源或提交数据 |
| PUT      | 更新资源           |
| DELETE   | 删除资源           |

不同请求方法通常对应不同的业务操作。

## 5. JSON 数据格式简介

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，常用于 Web API 的请求和响应。

例如：

```json
{
  "id": 1,
  "name": "我的技术文档",
  "description": "基于 MkDocs 构建的个人文档网站"
}
```

其中，数据由键值对组成，可以包含字符串、数字、数组和对象等类型。
